# Security policy

[English](SECURITY.en.md) | [עברית](SECURITY.md)

## Reporting a vulnerability or an exposed secret
Do not open a public issue. Use "Report a vulnerability" in the Security tab of the repository on GitHub, or contact the author through the profile listed in `NOTICE.en.md`.

Include: which file, what the problem is, how to reproduce it. Do not attach real secrets.

## Scope
The repository contains instruction text and small scripts. A relevant vulnerability is, for example: an instruction that leads to a secret being exposed, a way around an approval rule, or a script that writes outside its scope.

## No warranty
The protocol is provided as is, without warranty (see `LICENSE.md`). It reduces risk and does not guarantee security.
