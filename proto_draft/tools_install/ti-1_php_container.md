# ti-1: קונטיינר PHP בגרסה מקובעת (דוגמה להמחשה)

מודול: tools_install/ti-1 | פרויקט: protomotai | גרסה: 0.1 | סטטוס: טיוטה (דוגמה, ה-digest ריק בכוונה) | מצב: דלוק | תלוי ב: tools_install | רמת סיכון: גבוהה | עודכן: 2026-10-23 | עודכן על ידי: claude

- **סוג:** install (להתקנה או ייבוא)
- **תחום:** קונטיינרים
- **למה נדרש:** להריץ קוד PHP בסביבה מבודדת וידועה, בגרסה אחת שלא משתנה בין ריצות.
- **מה עושה:** מושך את האימג' הרשמי של PHP וממנו מריצים קוד PHP בתוך קונטיינר חולף.
- **מה נדרש ליישום או להתקנה:** docker מותקן ופועל; גישת רשת לרישום הרשמי; מקום בדיסק; אישור R2 להורדה.
- **סיכון ואכיפה:** הורדה: R2. הרצה: R2 לכל הרצה בפרויקט עם אפשרויות שמגבילות (ראה הערות). instruction-only; `verify_command` לפני כל שימוש.
- **כללי כשל-סגור:** pin חסר או צף (`latest`, `8`, `8.3`) = לא מתקינים. digest שאינו תואם לערך הרשום = לא מריצים (מצב `mismatch`).
- **בדיקות קבלה:** (1) `verify_command` מדפיס את ה-digest הצפוי. (2) קוד `php -v` רץ ומחזיר את הגרסה המקובעת. (3) הרצה עם `--network none` ועם mount לקריאה בלבד לא כותבת מחוץ לתיקיית העבודה.
- **מקור:** האימג' הרשמי `php` ברישום docker הרשמי (יש לאמת בעצמך את הכתובת והמפרסם לפני ההתקנה).
- **pin:** `php@sha256:<DIGEST>` - **ריק בכוונה בדוגמה**; ממלאים digest אמיתי שנבדק מול הרישום הרשמי, ורושמים אותו ב-`project_tools.md`.
- **verify_command:** `docker image inspect --format '{{index .RepoDigests 0}}' php:<תג>` (הערך שמודפס חייב להיות שווה ל-pin).
- **פרוטוקול אבטחה:** `security/downloads_installs.md`
- **הערות:** אפשרויות הרצה מומלצות: `--rm --read-only --network none --cap-drop ALL`, משתמש לא root, mount של תיקיית העבודה בלבד, בלי `--privileged`, בלי mount של סוקט docker, בלי העברת סודות כמשתני סביבה. הדוגמה נכתבה להמחשה ולא נוסתה בהתקנה.
